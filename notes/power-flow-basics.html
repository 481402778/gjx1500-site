电力系统潮流计算：从一张图到一个方程

潮流计算是《电力系统分析》里第一个真正需要「算」的问题。它听起来抽象， 但本质只是一句话：已知电网长什么样、怎么接、各点要多少功率，求各点电压是多少。

一、它在算什么

把电网画成一张图：节点是变电站或母线，边是输电线路。给定线路的阻抗、各节点的负荷和发电功率， 潮流计算要求出：

  • 每个节点的电压幅值 V 和相角 θ
  • 每条支路上流过的有功和无功
  • 全网损耗

有了这些，才能判断电压有没有越限、线路会不会过载、网损有多大。

二、核心是两组方程

对每个节点 i，注入的有功和无功可以写成所有节点电压的函数：

Pi = Vi · Σj Vj ( Gij cos θij + Bij sin θij )
Qi = Vi · Σj Vj ( Gij sin θij − Bij cos θij )

其中 θij = θi − θj，G、B 来自节点导纳矩阵 Y = G + jB。 这两组方程是非线性的——电压乘电压、还夹着三角函数，所以没有解析解，只能迭代。

三、节点分三类，方程才配得平

一张 n 个节点的网络有 2n 个未知量（每点一个 V、一个 θ），所以也必须给够 2n 个已知条件。

类型已知待求典型场景
PQ 节点P、QV、θ负荷节点
PV 节点P、VQ、θ发电机节点
平衡节点V、θP、Q系统参考点，一般只有一个

平衡节点的作用是兜底：全网损耗事先不知道，只能由它来补上那部分功率缺额。

四、牛顿-拉夫逊法：五步迭代

做法就是把非线性方程在当前点线性化，解一个线性方程组，再往前走一步，重复到收敛。

1. 给初值          V = 1.0，θ = 0
2. 算不平衡量      ΔP = P_给定 − P_计算
                  ΔQ = Q_给定 − Q_计算
3. 组装雅可比矩阵  J（对 V、θ 的偏导）
4. 解线性方程      J · [Δθ; ΔV/V] = [ΔP; ΔQ]
5. 更新并检查      V、θ 加上修正量，
                  若 max|ΔP, ΔQ| < ε 则收敛，否则回到第 2 步

ε 一般取 1e-5 到 1e-8（标幺值）。正常网络三四次迭代就收敛，初值给得好会更快。

雅可比矩阵是这一步最费事的地方：它随迭代变化，每次都要求一遍偏导。工程实现里通常会利用稀疏性加速。

五、为什么值得算

  • 电压越限判断：重负荷时末端电压可能掉到 0.9 标幺以下，必须提前发现
  • 网损估算：损耗直接等于成本
  • 后续分析的地基：稳定分析、短路计算、优化调度都建立在潮流结果之上
